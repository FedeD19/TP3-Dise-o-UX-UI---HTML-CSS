Algoritmos y Estructuras de Datos

Repaso de listas enlazadas, pilas, colas y su implementación en Python. Incluye ejercicios de recursión y las primeras nociones de complejidad temporal para comparar distintas soluciones a un mismo problema.

Programación Orientada a Objetos

Diseño de clases en Java, relaciones de herencia y polimorfismo. Se trabajan además los principios GRASP para tomar mejores decisiones de diseño frente a los cambios en los requisitos.

Fundamentos de la Programación

Lógica de programación, estructuras de control, funciones y una primera aproximación a algoritmos de búsqueda y ordenamiento como la búsqueda binaria y el selection sort.

Diseño UX-UI

Maquetado con HTML semántico y CSS moderno: Flexbox, Grid, variables CSS y buenas prácticas de accesibilidad, como las que se aplican en este mismo trabajo práctico.
