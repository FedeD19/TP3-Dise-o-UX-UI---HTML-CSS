Guía rápida: armar tu entorno de desarrollo

Pasos para empezar

  1. Instalar un editor de código, como Visual Studio Code.
  2. Instalar Git para poder clonar y versionar proyectos.
  3. Clonar el repositorio del trabajo práctico en tu computadora.
  4. Abrir la carpeta del ejercicio que quieras revisar.
  5. Abrir el archivo index.html con doble clic para verlo en el navegador.
